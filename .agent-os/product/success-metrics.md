# Success Metrics - MusicBrainz Explorer

## North Star Metric

**Primary Metric**: **Monthly Active Deep Explorers (MADE)**
- Definition: Users who explore 3+ related entities (artists, labels, releases) in a single session within 30 days
- Target: 70% of monthly active users
- Rationale: Measures core value delivery of relationship discovery and exploration

## Success Metric Measurement Framework

### Data Collection Methods

#### Quantitative Metrics
1. **Google Analytics 4**: Session tracking, user behavior, conversion funnels
2. **Custom Event Tracking**: Entity exploration, relationship depth, feature usage
3. **API Analytics**: Cache performance, error rates, response times
4. **Database Queries**: Export downloads, user progression milestones

#### Qualitative Metrics
1. **User Surveys**: Monthly satisfaction surveys, feature request feedback
2. **User Interviews**: Quarterly deep-dive interviews with power users
3. **Net Promoter Score**: Quarterly NPS surveys to measure advocacy
4. **Feature Feedback**: In-app feedback collection for new features

### Reporting Dashboard

#### Daily Metrics Dashboard
- Active users (last 24 hours)
- Session quality metrics
- Technical performance indicators
- Error rates and system health

#### Weekly Business Review
- User engagement trends
- Feature adoption rates  
- Retention cohort analysis
- Growth metrics and projections

#### Monthly Success Review
- North Star Metric performance
- All KPI progress vs. targets
- User feedback themes and insights
- Competitive landscape updates

## Success Thresholds & Escalation

### Green Zone (On Track)
- All metrics within 10% of target
- User satisfaction >4.0/5.0
- Technical performance stable
- Growth trending positively

### Yellow Zone (Attention Required)
- One or more metrics 10-25% below target
- User satisfaction 3.5-4.0/5.0
- Technical issues affecting <5% of users
- Growth rate declining but positive

### Red Zone (Intervention Required)
- Critical metrics >25% below target
- User satisfaction <3.5/5.0
- Technical issues affecting >5% of users
- Negative growth rate
